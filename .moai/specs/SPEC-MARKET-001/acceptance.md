# SPEC-MARKET-001: 인수 기준

## AC-001: 코스피 지수 표시
- [ ] 메인 페이지에 코스피 현재값이 표시된다
- [ ] 전일 대비 등락률이 빨간색(상승)/파란색(하락)으로 표시된다
- [ ] 당일 분봉 미니 라인 차트가 표시된다
- [ ] 시간축: 09:00~15:30 고정

## AC-002: 코스닥 지수 표시
- [ ] 메인 페이지에 코스닥 현재값이 표시된다
- [ ] 전일 대비 등락률이 색상으로 구분된다
- [ ] 당일 분봉 미니 라인 차트가 표시된다

## AC-003: USD/KRW 환율 표시
- [ ] 메인 페이지에 현재 USD/KRW 환율이 표시된다
- [ ] 전일 대비 등락률이 표시된다
- [ ] 최근 30일 라인 차트가 표시된다

## AC-004: 반응형 레이아웃
- [ ] Desktop (>=768px): 3열 가로 배열
- [ ] Mobile (<768px): 1열 세로 배열

## AC-005: 에러 격리
- [ ] 코스피 API 실패 시 코스닥/환율은 정상 표시
- [ ] 환율 API 실패 시 코스피/코스닥은 정상 표시
- [ ] 각 카드에 개별 에러 메시지 표시

## AC-006: 캐시
- [ ] 지수 데이터: 1분 캐시 (장중 갱신)
- [ ] 환율 데이터: 1시간 캐시

## AC-007: 테스트
- [ ] 업종 지수 API 테스트 통과
- [ ] 환율 API 테스트 통과
- [ ] API 라우트 테스트 통과
- [ ] 전체 테스트 스위트 통과 (기존 110개 + 신규)
