# Stock Watchlist - 제품 개요

## 프로젝트 설명

Stock Watchlist는 한국 주식 시장의 실시간 정보를 추적하고 관리하는 웹 애플리케이션입니다. 사용자는 관심 있는 종목을 등록하고 실시간 주가 정보, 뉴스, 공시 정보를 한 곳에서 확인할 수 있습니다.

## 목표 사용자

- **개인 투자자**: 자신의 관심종목 포트폴리오를 관리하고 싶은 분들
- **주식 트레이더**: 실시간 시세 정보와 뉴스를 빠르게 확인하고 싶은 분들
- **재테크 관심자**: 한국 주식 시장 동향을 파악하고 싶은 분들

## 핵심 기능

### 1. 종목 검색
- 키움증권 REST API 기반 전종목 검색
- 한글 종목명 지원
- 7일 캐시로 빠른 검색 (점수 기반 매칭)
- KOSPI/KOSDAQ 시장 구분

### 2. 관심종목 관리
- 종목 추가/삭제 기능
- 사용자별 개인화된 워치리스트
- 드래그 앤 드롭 순서 변경 (계획)
- 여러 사용자 지원 (다중 User 모델)
- stock_auto 자동 동기화 (추가/삭제 시 fire-and-forget)

### 3. 실시간 주식 정보
- 기본 OHLCV 데이터 (시가/고가/저가/종가/거래량)
- 시가총액, 거래대금, 상장주식수
- 거래량 비중 (30일 평균 대비)
- 52주 최고가/최저가
- 등락률/등락폭
- 데이터 캐싱으로 빠른 로딩 (30초 TTL)

### 4. 주가 차트
- 봉형 차트: 일봉/주봉/월봉 (키움증권 REST API ka10081/ka10082/ka10083)
- 라인 차트: 기간별 시세 (1일/3개월/1년/3년/10년)
- 분봉(인트라데이) 차트: 당일 분 단위 가격 변동 (ka10080, 장중 데이터)
- 봉 타입과 기간 상호 배타적 UI 선택
- 캐싱 최적화 (분봉 5분, 일봉 1시간, 주봉/월봉 1일 TTL)
- 장외시간 지원 (1일 차트는 최근 거래일 데이터만 표시)

### 5. 뉴스 및 공시 정보
- 종목별 관련 뉴스 (네이버 뉴스 API, Node.js native fetch)
- 전자공시시스템(DART) 공시 정보 (Node.js native fetch)
- 미등록 종목 및 API 미설정 시 샘플 데이터 반환

### 6. 시장 지표 대시보드
- 코스피/코스닥/USD/KRW 환율 지표 (SPEC-MARKET-001)
- 미니 차트로 시장 동향 한눈에 파악
- 탭 선택 UI로 지표 전환
- 상세 차트 뷰 (이전장 종가 참고선 표시)
- 인트라데이 가격 변동 및 등락률 표시

### 7. 반응형 UI
- 모바일/태블릿/데스크톱 지원
- Tailwind CSS 기반 현대적인 디자인
- 직관적인 사용자 인터페이스

## 사용자 스토리

### 관심종목 추가
```
사용자로서:
나는 관심 있는 종목을 검색하여 추가하고 싶다
그래서:
내 포트폴리오의 실시간 현황을 한눈에 볼 수 있다
```

### 실시간 시세 확인
```
사용자로서:
나는 등록된 종목의 실시간 주가 정보를 보고 싶다
그래서:
빠른 의사결정을 할 수 있다
```

### 뉴스 확인
```
사용자로서:
나는 관심종목의 최신 뉴스를 확인하고 싶다
그래서:
시장 동향을 파악할 수 있다
```

## 제약 사항

- 한국 주식 시장 (KOSPI, KOSDAQ)만 지원
- 데이터 업데이트는 장 중 실시간 (30초 캐시)
- API 호출 제한으로 인해 과도한 요청 시 지연 가능

## 완성된 기능 (2026-04-17)

- SPEC-API-001: 키움증권 REST API 완전 전환 (PyKRX 제거)
- SPEC-CHART-001: 일봉/주봉 차트 (lightweight-charts v5)
- SPEC-CHART-002: 차트 UI 개편 (봉/기간 상호 배타적 선택)
- SPEC-CHART-003: 분봉 인트라데이 차트 지원
- SPEC-API-002: 토큰 만료 처리 강화 (자동 재시도)
- SPEC-MARKET-001: 시장 지표 대시보드 (코스피/코스닥/환율, 미니차트)
- SPEC-POLL-001: 주기적 데이터 폴링 시스템 (SWR + 장시간 동적 인터벌)
- SPEC-MASHUP-003: AI 시그널 프록시 API + UI 패널
- SPEC-MASHUP-004: AI 종목 발굴 프록시 API + UI 패널
- SPEC-MASHUP-005: 관심종목 동기화 (stock_auto ↔ stock_watchlist)
- 뉴스/공시 API: Python→Node.js native fetch 전환
- 차트 개선: 1일 차트 시간축 (08:00~16:30), HH:MM 포맷, 이전장 종가/시가 참고선

## 향후 계획

- 포트폴리오 수익률 분석
- 기술적 지표 표시 (이동평균선, RSI, MACD 등)
- 알림 설정 (가격 변동/뉴스 알림)
- 종목 비교 기능
- 고급 검색 필터
