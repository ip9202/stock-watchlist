# Stock Watchlist - 제품 개요

## 프로젝트 설명

Stock Watchlist는 한국 주식 시장의 실시간 정보를 추적하고 관리하는 웹 애플리케이션입니다. 사용자는 관심 있는 종목을 등록하고 실시간 주가 정보, 뉴스, 공시 정보를 한 곳에서 확인할 수 있습니다.

## 목표 사용자

- **개인 투자자**: 자신의 관심종목 포트폴리오를 관리하고 싶은 분들
- **주식 트레이더**: 실시간 시세 정보와 뉴스를 빠르게 확인하고 싶은 분들
- **재테크 관심자**: 한국 주식 시장 동향을 파악하고 싶은 분들

## 핵심 기능

### 1. 종목 검색
- 키움증권 REST API 기반 전종목 검색
- 한글 종목명 지원
- 7일 캐시로 빠른 검색 (점수 기반 매칭)
- KOSPI/KOSDAQ 시장 구분

### 2. 관심종목 관리
- 종목 추가/삭제 기능
- 사용자별 개인화된 워치리스트
- 드래그 앤 드롭 순서 변경 (계획)
- 여러 사용자 지원 (다중 User 모델)

### 3. 실시간 주식 정보
- 기본 OHLCV 데이터 (시가/고가/저가/종가/거래량)
- 시가총액, 거래대금, 상장주식수
- 거래량 비중 (30일 평균 대비)
- 52주 최고가/최저가
- 등락률/등락폭
- 데이터 캐싱으로 빠른 로딩 (30초 TTL)

### 4. 주가 차트
- 일봉 및 주봉 차트 (키움증권 REST API)
- 캔들스틱/라인 차트 전환
- 시간프레임 선택 (1M, 3M, 6M, 1Y, 5Y)
- 자동 페이지네이션 (최대 5회)
- 캐싱 최적화 (일봉 1시간, 주봉 1일 TTL)

### 5. 뉴스 및 공시 정보
- 종목별 관련 뉴스 (네이버 금융 API)
- 전자공시시스템(DART) 공시 정보
- 실시간 업데이트

### 6. 반응형 UI
- 모바일/태블릿/데스크톱 지원
- Tailwind CSS 기반 현대적인 디자인
- 직관적인 사용자 인터페이스

## 사용자 스토리

### 관심종목 추가
```
사용자로서:
나는 관심 있는 종목을 검색하여 추가하고 싶다
그래서:
내 포트폴리오의 실시간 현황을 한눈에 볼 수 있다
```

### 실시간 시세 확인
```
사용자로서:
나는 등록된 종목의 실시간 주가 정보를 보고 싶다
그래서:
빠른 의사결정을 할 수 있다
```

### 뉴스 확인
```
사용자로서:
나는 관심종목의 최신 뉴스를 확인하고 싶다
그래서:
시장 동향을 파악할 수 있다
```

## 제약 사항

- 한국 주식 시장 (KOSPI, KOSDAQ)만 지원
- 데이터 업데이트는 장 중 실시간 (30초 캐시)
- API 호출 제한으로 인해 과도한 요청 시 지연 가능
